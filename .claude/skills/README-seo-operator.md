# SEO Operator skills

These 22 skills come from [marketingskills/seo](https://github.com/marketingskills/seo) at commit `6f45586` (MIT licence, see `LICENSE-seo-operator`). Claude Code picks them up automatically from `.claude/skills/`.

The upstream `live-search-console-data` skill is left out on purpose. It sends Search Console and GA4 data through a third-party service (refreshagent.com) and needs an API key. The other skills work with data you paste in, such as GSC exports, crawl output or SERPs.

To update, re-copy `skills/*` from the upstream repo.
